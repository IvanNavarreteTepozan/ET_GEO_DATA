# Análisis Exploratorio de Datos Geoespaciales en México

Este repositorio contiene un proyecto de **análisis exploratorio** aplicado a mapas del territorio mexicano.  
El trabajo se centra en el uso de **capas vectoriales** y **mapas tipo raster**, con el objetivo de estudiar y visualizar información geográfica relevante.

## Contenido
- Procesamiento y visualización de **mapas raster**.
- Integración de **capas vectoriales** para enriquecer el análisis.
- Exploración de distintos sectores económicos del país.
- Identificación de posibles mercados a partir de patrones espaciales.

## Objetivo
El propósito principal de este proyecto es **analizar los sectores económicos y los posibles mercados en México** mediante herramientas de análisis geoespacial.  
Se busca mostrar cómo los datos geográficos pueden apoyar la toma de decisiones estratégicas y ofrecer una visión más clara de la distribución territorial de actividades económicas.

---

💡 Este proyecto sirve como introducción práctica al uso de **datos geoespaciales** en el análisis económico y de mercado, combinando mapas raster y capas vectoriales para obtener una perspectiva integral del territorio mexicano.
